# Share Text

Kyowa Sketch is a local Codex-powered writing interface where the AI lightly reads your unfinished draft while you type. It has no Send button: after a 4-second pause, weak provisional readings appear in the side rail. No API key is required; it uses your local Codex/ChatGPT login.

```bash
git clone <REPO_URL>
cd kyowa-sketch
codex
npm start
```

Then open:

```text
http://localhost:8787
```

Use the AI toggle or the daily limits if you want to keep usage low.
